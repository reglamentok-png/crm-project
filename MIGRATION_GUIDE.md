# Руководство по миграции и автоматическому обновлению

## Обзор

В CRM системе управления контактами реализовано автоматическое обновление страницы при изменении базы данных. Система поддерживает как PostgreSQL, так и SQLite базы данных.

## Автоматическое обновление

### Что реализовано

1. **Polling механизм**: Фронтенд автоматически обновляет список контактов каждые 10 секунд
2. **Управление обновлением**: Пользователь может включить/выключить автообновление через переключатель в Header
3. **Визуальная обратная связь**: Отображается время последнего обновления
4. **Адаптивный дизайн**: Интерфейс оптимизирован для мобильных устройств

### Как это работает

- При загрузке страницы автоматически загружаются контакты
- Если автообновление включено, каждые 10 секунд отправляется запрос к API `/api/contacts`
- Время последнего обновления отображается в реальном времени
- Пользователь может вручную обновить контакты кнопкой "Обновить"

## Миграция между базами данных

### Текущая конфигурация

Система использует универсальный сервер (`server-modified.js`), который поддерживает:
- **PostgreSQL** (при установленном PostgreSQL и правильной настройке DATABASE_URL)
- **SQLite** (используется по умолчанию, не требует установки дополнительного ПО)

### Запуск с разными базами данных

#### Вариант 1: Использование SQLite (по умолчанию)
```
cd crm-project\backend
node server-modified.js
```
Или используйте `start.bat` и выберите вариант 2.

#### Вариант 2: Использование PostgreSQL
1. Установите PostgreSQL (см. POSTGRESQL_SETUP.md)
2. Настройте DATABASE_URL в `backend/.env`
3. Запустите:
```
cd crm-project\backend
set USE_POSTGRESQL=true
node server-modified.js
```
Или используйте `start.bat` и выберите вариант 1.

### Миграция данных из SQLite в PostgreSQL

1. **Экспорт данных из SQLite**:
```bash
sqlite3 contacts.db .dump > export.sql
```

2. **Адаптация SQL файла**:
   - Замените `AUTOINCREMENT` на `SERIAL`
   - Замените `TEXT` на `VARCHAR(255)` для name и email
   - Замените `TEXT` на `VARCHAR(50)` для phone

3. **Импорт в PostgreSQL**:
```bash
psql -U postgres -d crm_database -f export_adapted.sql
```

## Архитектура

### Фронтенд (React)
- `src/App.js` - основной компонент с логикой автоматического обновления
- `src/components/Header.js` - компонент с переключателем автообновления
- `src/components/ContactList.js` - отображение списка контактов

### Бэкенд (Node.js + Express)
- `server-modified.js` - универсальный сервер с поддержкой PostgreSQL и SQLite
- `server.js` - оригинальный сервер только для PostgreSQL

### Конфигурация
- `backend/.env` - настройки базы данных
- `start.bat` - скрипт запуска с выбором базы данных

## Настройка интервала обновления

Чтобы изменить интервал автоматического обновления, отредактируйте файл `frontend/src/App.js`:

```javascript
// Автоматическое обновление контактов каждые 10 секунд
useEffect(() => {
  let intervalId;
  
  if (autoRefresh) {
    intervalId = setInterval(() => {
      fetchContacts();
    }, 10000); // Измените это значение (в миллисекундах)
  }
  
  return () => {
    if (intervalId) {
      clearInterval(intervalId);
    }
  };
}, [autoRefresh]);
```

## Устранение неполадок

### Автоматическое обновление не работает
1. Проверьте, включено ли автообновление (переключатель в Header)
2. Проверьте консоль браузера на наличие ошибок
3. Убедитесь, что бэкенд сервер работает (`http://localhost:5001/api/health`)

### Ошибки подключения к базе данных
1. **Для PostgreSQL**: Проверьте, запущен ли PostgreSQL сервер
2. **Для SQLite**: Убедитесь, что файл `contacts.db` существует в папке `backend`
3. Проверьте настройки в `backend/.env`

### Производительность
- При большом количестве контактов увеличьте интервал обновления
- Рассмотрите использование WebSocket для более эффективного обновления
- Для продакшена отключите автообновление или увеличьте интервал

## Дальнейшее развитие

### WebSocket реализация
Для реального времени можно заменить polling на WebSocket:
1. Установить `socket.io` на бэкенде и фронтенде
2. Отправлять события при изменении базы данных
3. Обновлять фронтенд только при фактических изменениях

### Оптимизация
1. Добавить дебаунс для запросов
2. Реализовать дифференциальное обновление (только измененные контакты)
3. Добавить индикатор "новых" контактов

## Заключение

Система теперь автоматически обновляет контакты при их изменении в базе данных. Пользователи могут добавлять контакты с телефона и видеть их на компьютере без необходимости ручного обновления страницы.

Для перехода на PostgreSQL достаточно установить PostgreSQL, настроить DATABASE_URL и установить `USE_POSTGRESQL=true`.
