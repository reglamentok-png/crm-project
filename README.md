# CRM для управления контактами

Полнофункциональная CRM система для управления контактами, построенная на стеке Node.js + Express + React + SQLite.

## Функциональность

- 📋 Просмотр списка контактов (имя, email, телефон)
- ➕ Добавление новых контактов
- ❌ Удаление контактов
- 🔄 Автоматическое обновление списка
- 📱 Адаптивный дизайн
- ⚡ Быстрая работа с базой данных SQLite

## Технологии

### Бэкенд
- **Node.js** - среда выполнения JavaScript
- **Express** - веб-фреймворк для Node.js
- **SQLite** - легковесная база данных
- **CORS** - обработка кросс-доменных запросов

### Фронтенд
- **React** - библиотека для построения пользовательских интерфейсов
- **Bootstrap 5** - CSS-фреймворк для адаптивного дизайна
- **Bootstrap Icons** - набор иконок
- **Fetch API** - для HTTP-запросов к бэкенду

## Установка и запуск

### 1. Клонирование и навигация
```bash
cd crm-project
```

### 2. Запуск бэкенда
```bash
cd backend
npm install
npm start
```
Бэкенд будет доступен по адресу: http://localhost:5001

### 3. Запуск фронтенда (в новом терминале)
```bash
cd frontend
npm install
npm start
```
Фронтенд будет доступен по адресу: http://localhost:3000

## API Endpoints

### Контакты
- `GET /api/contacts` - получить все контакты
- `GET /api/contacts/:id` - получить контакт по ID
- `POST /api/contacts` - создать новый контакт
- `PUT /api/contacts/:id` - обновить контакт
- `DELETE /api/contacts/:id` - удалить контакт

### Пример запроса на создание контакта
```json
POST /api/contacts
Content-Type: application/json

{
  "name": "Иван Иванов",
  "email": "ivan@example.com",
  "phone": "+7 (123) 456-78-90"
}
```

## Особенности реализации

1. **Автоматическое создание базы данных** - SQLite база создается при первом запуске
2. **Тестовые данные** - при первом запуске добавляются 3 тестовых контакта
3. **Валидация** - проверка обязательных полей и формата email
4. **Обработка ошибок** - подробные сообщения об ошибках на клиенте и сервере
5. **Адаптивный дизайн** - корректное отображение на мобильных устройствах
6. **Индикаторы загрузки** - спиннеры при выполнении операций

## Скриншоты

1. **Главная страница** - форма добавления и список контактов
2. **Успешное добавление** - уведомление об успешном создании контакта
3. **Удаление контакта** - подтверждение перед удалением
4. **Адаптивный вид** - корректное отображение на мобильных устройствах
